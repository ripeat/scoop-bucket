# ripeat Scoop bucket

The [ripeat](https://github.com/ripeat/releases) manifest for Windows.

Scoop needs `git` to add a bucket, so install that first:

```powershell
scoop install git
scoop bucket add ripeat https://github.com/ripeat/scoop-bucket
scoop install ripeat
```

Update with `scoop update ripeat`. Check with `ripeat version`.

Downloads, checksums and basic steps: https://github.com/ripeat/releases
